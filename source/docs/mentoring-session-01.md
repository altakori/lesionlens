# 1회차 기획 멘토링 준비

## 이번 회차 수행 방향

LesionLens의 문제 정의와 4주 MVP 범위를 확정한다. “더 좋은 진단 모델”이 아니라, 여러 모델의 불일치와 영상 품질 신호로 추가 확인 가치가 큰 검사를 먼저 정렬하는 품질관리 계층으로 범위를 제한한다.

## 현재까지 준비한 내용

- 문제: 평균 분할 성능이 양호해도 작은 병변 놓침이 남고, 민감도를 높이면 FP/case가 증가할 수 있다.
- 현재 근거: 과거 개발 비교와 9증례 사후 탐색 파일럿은 구현 가능성 신호일 뿐 독립 성능 근거가 아니다.
- 검증 계획: 공개 데이터에서 환자 단위로 train/calibration/held-out test를 분리하고, 점수식과 코드를 동결한 뒤 같은 검토량의 무작위 대기열과 비교한다.
- 구현: 합성 사례로 대기열·순위 근거·업무량 조절·한계 문구를 보여 주는 대시보드 MVP를 만들었다.
- 안전 경계: 실제 환자자료·식별자·진단/치료 권고를 포함하지 않는다.

## 멘토에게 확인할 질문

1. 1차 사용자를 영상의학과 전문의로 고정하는 것이 좋은가, 의료영상 QA 담당자까지 포함하는 것이 좋은가?
2. 4주 MVP의 주 KPI를 “같은 업무량에서 무작위 대비 FN 부담 포착률”로 두는 것이 적절한가?
3. 최소 효과 기준을 차이의 95% CI가 0을 넘는 것으로 둘지, 인큐베이팅 단계에 맞는 현실적인 기준이 따로 있는가?
4. 불일치·작은 연결요소 후보·영상 품질 중 반드시 남겨야 할 최소 신호는 무엇인가?
5. 10월 3일 데모에서 대기열, 사례 상세 근거, 업무량 조절 중 어떤 화면을 우선해야 하는가?
6. 공개 데이터 기반 가치 검증과 향후 의료진 사용성 검증의 경계를 어떻게 설명하면 과장 없이 설득력이 있는가?
7. 팀원 역할을 AI/백엔드와 사용자 흐름·문서화로 나누는 현재 R&R이 4주 일정에 적절한가?
