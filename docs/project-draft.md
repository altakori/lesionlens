# 프로젝트 초안

## 한 줄 소개

여러 의료영상 AI의 판단 차이와 영상 품질 신호를 결합해, 의료진이 **추가 확인 가치가 큰 간 CT부터 보되 전체 검사를 누락하지 않도록** 돕는 human-in-the-loop 품질관리 도구.

## 문제와 가설

**검증할 가설:** 간 종양 분할 AI에서는 작은 병변 놓침과 민감도·오탐 간 상충이 발생할 수 있다. 모델 간 불일치, 작은 연결요소 후보, 영상 품질을 이용한 추가 확인 가치 순위가 같은 재검토 업무량의 무작위 순서보다 기존 놓침 부담을 더 많이 포함하는지 공개 데이터의 고정 평가셋에서 검증한다. 데이터셋 범위와 모델 provenance가 확정되기 전에는 이를 성능 사실로 주장하지 않는다.

현재 도구가 계산하는 것은 임상적 위급도·전이 가능성·완치 가능성이 아니라 **추가 확인 가치**다. 기본 대기열은 모든 검사를 유지한 채 이 값을 기준으로 정렬하며, 낮은 순위는 정상 판정이나 검토 제외를 뜻하지 않는다.

## 사용자와 서비스 목적

- 1차 사용자: 다수의 간 CT를 검토하는 영상의학과 의료진
- 보조 사용자: 같은 근거와 실패 유형을 점검하는 의료영상 QA 담당자
- 간접 수혜자: 간암 고위험군·추적검사 환자
- 사용자가 하려는 일: 대기열 상단에서 먼저 확인할 검사를 고르고, 후보 위치와 순위 근거를 확인한 뒤 기존 판독·QA 흐름으로 돌아간다.
- 하지 않는 일: 검사를 숨기거나 진단·치료를 결정하고, 임상적 응급도를 산출하지 않는다.

## 사례 분류 초안

| 사례 | 관찰 신호 | 대기열 상태 | 화면 설명 | 한계 |
|---|---|---|---|---|
| 모델 간 위치·부피 불일치 | 마스크 차이, 연결요소 수 차이 | 먼저 확인 후보 | 모델 불일치 | 공통 실패 탐지 어려움 |
| 한 모델만 표시한 작은 후보 | 작은 연결요소, 단독 후보 | 먼저 확인 후보 | 작은 병변 후보 | 병변 확률이 아님 |
| 간 경계 인접 후보 | 경계부 마스크 변동 | 먼저 확인 후보 | 경계 인접 후보 | 오탐 가능성 큼 |
| 절편 간격·영상 품질 이상 | 품질 플래그 | 품질 확인 | 품질 확인 | 질환 위험과 별개 |
| 낮은 불일치·품질 플래그 없음 | 낮은 합성 신호 | 일반 순서 | 일반 순서 | 정상 판정이 아님 |
| 응급·전이·완치 가능성 | 현재 입력으로 판정 불가 | 비범위 | 표시하지 않음 | 임상 정보·검증 필요 |

## 4주 MVP

1. 공개 코호트와 평가 계약 확인
2. 환자 단위 분리 및 누수 검사
3. calibration에서 점수식·가중치·임계값 결정
4. 코드·설정·입력 목록 해시 후 동결
5. held-out test에서 상위 10/20/30% 대기열 평가
6. 무작위 대조와 95% CI 보고
7. 대기열·근거·한계를 보여 주는 최소 뷰어

## 현재 데모 화면과 데이터 경계

- **전체 대기열:** 모든 검사를 유지하고 추가 확인 가치 순으로 정렬한다.
- **실제 공개 CT 확인:** 로컬에 준비된 public non-PHI LiTS CT 3건과 데이터셋 종양 정답 주석(GT)을 분리된 뷰어에서 확인한다. GT는 AI 예측이나 진단 결과가 아니다.
- **합성 사례 상세:** 합성 CT, 후보 위치, 이유 태그, 모델 신호와 해석 한계를 함께 보여 준다. 이 화면의 점수와 후보는 합성 데모 값이다.
- **평가 요약(후속 구현):** held-out 평가가 준비되면 상위 10/20/30% operating point의 예상 FN 부담 포착률을 사용자용 대기열 조작과 분리해 보여 준다. 현재 합성 데모에는 평가 계약만 표시한다.
- **기준·한계:** `먼저 확인`, `품질 확인`, `일반 순서`의 기준과 공통 실패·임상 적용 한계를 설명한다.

정렬은 무엇부터 볼지를 바꾸고 사례를 제거하지 않는다. 보기 필터는 탐색 편의를 위한 것이며, 숨겨진 사례가 안전하거나 검토 불필요하다는 뜻이 아니다.

## 역할 초안

- 박상혁: AI/백엔드, 평가 계약, 실험·재현성, 대시보드 구현
- 마리아: 사용자 흐름, 경쟁/유사 서비스 조사, 문서·발표, 데모 시나리오

## 성공 판정

- 작은 병변 민감도와 FP/case를 함께 보고한다.
- 우선순위와 동일 건수 무작위 대조의 차이 및 95% CI를 보고한다.
- 모든 사례 상세에 최소 한 개의 근거와 한계 문구를 표시한다.
- 같은 고정 입력·버전에서 대기열 순서와 집계 수치가 재현된다.
- 모든 주요 화면 영역과 조작에 사용 목적을 한 문장으로 설명할 수 있다.
- 임상 확률이 아닌 합성 신호 점수에는 `진단 확률 아님`을 표시한다.

## 비범위

- 실제 환자자료 업로드
- 임상 성능 또는 일반화 주장
- 진단·치료 권고
- 기관별 보정·월별 QA·의료진 사용성 평가
- 임상적 위급도·전이 가능성·완치 가능성 산출
