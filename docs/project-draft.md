# 프로젝트 초안

## 한 줄 소개

여러 의료영상 AI의 판단 차이와 영상 품질 신호를 결합해 의료진이 먼저 다시 볼 간 CT를 정하는 human-in-the-loop 품질관리 도구.

## 문제와 가설

간 종양 분할 AI는 작은 병변을 놓칠 수 있고 민감도를 높이면 오탐이 늘 수 있다. 모델 간 불일치, 작은 연결요소 후보, 영상 품질을 이용한 위험순위가 같은 재검토 업무량의 무작위 순서보다 기존 놓침 부담을 더 많이 포함할 수 있다는 가설을 검증한다.

## 4주 MVP

1. 공개 코호트와 평가 계약 확인
2. 환자 단위 분리 및 누수 검사
3. calibration에서 점수식·가중치·임계값 결정
4. 코드·설정·입력 목록 해시 후 동결
5. held-out test에서 상위 10/20/30% 대기열 평가
6. 무작위 대조와 95% CI 보고
7. 대기열·근거·한계를 보여 주는 최소 뷰어

## 필수 화면

- 재검토 대기열
- 사례별 순위 근거와 모델 신호 비교
- 검토량별 예상 FN 부담 포착률
- 데이터·공통 실패·임상 적용 한계

## 역할 초안

- 박상혁: AI/백엔드, 평가 계약, 실험·재현성, 대시보드 구현
- 마리아: 사용자 흐름, 경쟁/유사 서비스 조사, 문서·발표, 데모 시나리오

## 성공 판정

- 작은 병변 민감도와 FP/case를 함께 보고한다.
- 우선순위와 동일 건수 무작위 대조의 차이 및 95% CI를 보고한다.
- 모든 사례 상세에 최소 한 개의 근거와 한계 문구를 표시한다.
- 같은 고정 입력·버전에서 대기열 순서와 집계 수치가 재현된다.

## 비범위

- 실제 환자자료 업로드
- 임상 성능 또는 일반화 주장
- 진단·치료 권고
- 기관별 보정·월별 QA·의료진 사용성 평가
