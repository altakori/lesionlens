# Grok 적대적 검토 — 부모 검증·판정

## 범위와 증거
- 사용자가 이번 작업에 Grok 사용을 명시 승인했다. xAI OAuth, grok-4.6, 단일 검토 응답 완료. fallback 없음.
- 현재 Notion 기획서를 페이지네이션으로 직접 조회하고 실행 앱을 Windows Chrome으로 다시 관찰했다.
- Grok에는 익명화한 제품/멘토 피드백 요약 및 관찰 결과만 전달했다. 원문 녹취·인명·비공개 코드·CT 영상·계정 정보를 전달하지 않았다.
- Grok은 직접 Notion/브라우저/스크린샷을 보지 않았다. UI 정보구조 검토이며 시각적 품질 점수나 MD 사용성 검증이 아니다.
- 원응답: grok-adversarial-review.md. 입력: grok-review-input.txt. 호출 증빙: grok-review-receipt.json.

## 채택: 직접 확인된 사실
1. 현재 실행 앱은 ID/GT 부피순 정렬의 매칭 CT 뷰어이며, 아직 근거 기반 우선순위 큐가 아니다.
2. 초기 화면에서 CT가 자동 노출된다. 최신 승인 흐름인 카테고리/카드 → CT 보기와 불일치한다.
3. 실제 필터는 전체/미검토/완료뿐이다. 병변 크기/개수/분포 태그, 선정 이유와 확인 체크리스트가 없다.
4. 전체 GT 부피는 개별 병변 크기·개수·분포와 같지 않다. GT 기반 정렬을 미지 사례의 모델 우선순위 성능으로 평가하면 누수다. GT 탐색/교육 자체는 유효하다.
5. CT와 사례 ID·GT 정합성이 검증되어 있지만 그것은 임상 유용성·순위 타당성의 증거가 아니다.
6. 현재 3개 선택 양성 사례로 일반화된 검토 효율을 주장할 수 없다.
7. 병리학과 MD는 사용자가 정한 대상이다. CT 목록에서 어떤 협업 결정을 하는지는 검증 필요하나 대상에서 임의 제외하지 않는다.

## 수정 또는 기각: Grok의 과도한 판단
- '양성 사례만이면 대기열이 불필요': 기각. 양성끼리도 확인 우선순위는 가능하다. 여기서 문제는 사례 다양성/검증 부족이지 양성 여부 자체가 아니다.
- 'top10/20/30 UI가 없으므로 모호성 해소 미충족': 기각. 주 화면에서 연구 operating point를 제거하고 문서에서 평가 용도로 분리한 것은 개선이다. 남은 문제는 미래 계획과 현재 기능의 설명 정합성이다.
- '모든 패널에 목적 문장이 없으면 실패': 축소. 멘토 요구는 설계자가 목적을 설명할 수 있어야 한다는 뜻이지, 화면마다 장황한 목적 문장을 붙이라는 확정 지시가 아니다.
- '검토 완료를 표시만 숨김으로 바꿔야 함': 기각. 실제 동작은 로컬 검토 상태 기록이지 단순 숨김이 아니다. 로컬 저장 범위/담당자 미기록을 정확히 안내하고 완료와 판독 확정을 분리하면 된다.
- '뷰어 DOM 자체가 없어야 함': 불필요한 구현 제약. 초기 비노출, 사용자 클릭 후 연결, 닫기/포커스 복귀가 사용자 요구다. DOM 존재 자체는 결함이 아니다.
- '뷰어가 있으면 목록 비교 불가능': 과장. 현재 나란히 있는 목록에서도 비교는 가능하지만 사용자 승인된 정보 우선순위와 다르다.
- '현재 기획이 우선순위 완료를 거짓 주장': 기각. Notion은 신규 요구의 미구현을 명시한다. 제품 목적과 구현 사이의 공백은 사실이나 문서의 허위 완료 주장은 아니다.
- 병리 사용자 제거 및 데모 문구 재도입을 자동 채택하지 않는다. 사용자 의도와 충돌하고 효용 증거가 부족하다. 반복 배너 대신 간결한 데이터/모델 출처와 기능 상태를 유지한다.

## 추천 우선순위
P0: 카드/카테고리 우선 흐름과 명시적 CT 보기. 원본 사례 ID·측정 출처·왜 볼지·어디를 볼지·검토 상태가 카드의 핵심이다.
P0: '먼저 확인'의 기준을 현실 사례와 MD 과업에서 정한다. 사용자 승인 없는 임상 가중치/임계값을 생성하지 않는다. 초기에는 명시적 MD 지정 순서와 초안 규칙을 구분할 수 있다.
P1: 크기/개수/분포의 실제 측정 정의. 전체 종양 부피와 최대 직경/연결요소 수/해부학적 분포를 혼동하지 않는다. 단순 연결요소를 확정 병변 개수로 단정하지 않는다.
P1: 병리 협업의 결정·의뢰 맥락·출력 확인. CT 단독 병리 진단을 만들지 않는다.
P1: 실제 이용자 과업 시험: 왜 첫 사례인지 설명, 특정 사례 찾기, CT 열기/닫기, 검토 기록, 필터 해제 후 전체 복귀. 정확성/오해/시간을 관찰하되 작은 관찰을 임상 효과로 일반화하지 않는다.
P2: 모델 결과가 준비되면 GT 없는 입력으로 순위를 생성하고 고정 holdout에서 도착순/무작위/기존 업무 기준선과 같은 검토량으로 비교. 누락/실패/동점/불확실성도 평가.

## 이번 작업 결과
읽기 전용 적대적 검토와 검토 산출물 저장만 수행했다. 앱 코드 및 Notion 내용은 변경하지 않았다. 미학·대비·글자 크기에 대한 최종 시각 QA는 이번 외부 검토에서 수행하지 않았다.
