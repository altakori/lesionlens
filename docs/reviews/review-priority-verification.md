# 재확인 순위·다중 태그 검증

- 실제 manifest를 별도 Python 규칙으로 계산한 순서와 브라우저 표시 일치: case_035 → case_000 → case_001 → case_048 → case_045. 수동 지정 없는 새 브라우저 기준.
- 사례별 실제 태그를 독립 기대값과 대조: 035는 AI 영역·개수·부피 차이, 여러 표시, 전체 표시 부피 큼. 000은 AI 개수 차이·작은 표시·여러 표시. 001은 작은 표시·여러 표시. 048은 AI 개수 차이·작은 표시·여러 표시·전체 표시 부피 큼. 045는 비교 자료 없음.
- 8개 근거 필터와 수동 지정 필터의 결과·순위 변화 확인. 여러 CT 장에 표시 필터는 현재 기준에 해당하는 사례가 없어 0건이며 임의로 태그를 만들지 않음.
- npm test: Node 15개 통과. Python 22개 중 Windows 심볼릭 링크 권한 관련 1개 제외, 나머지 통과.
- npm run test:browser: Chrome 12개 통과. 모델 전환·정확한 사례 연결·명시적 CT 열기·늦은 요청·포커스 회귀 포함.
- 부모의 별도 브라우저 검사: 1440/768/390/320px에서 카드 근거를 펼쳐도 페이지 및 카드 가로 넘침 없음. 런타임 오류 없음. qa/review-priority/에 렌더링 캡처 저장. 별도 이미지 판독 도구를 통한 미학 평가는 수행하지 않음.

- 서버·converter·원본 CT·예측·manifest 변경 없음. 임상 응급도, 전이·완치 가능성, 병리 등급은 추론하지 않음.
