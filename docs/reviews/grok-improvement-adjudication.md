# Grok 개선안 채택 판정

원문: grok-improvement-prompt.md. 제안은 실행 지침이 아니라 검토자료다.

채택: 크기/연결성분수 두 축의 비지배 그룹, 그룹내ID, 일반태그와 순위근거 분리, 기본큐/추천/집계 일치, 장문 상세이동, 문서단일화. 임상점수/컷/새데이터/학습 없음.

교정: 파레토 그룹은 비교 집합에 의존한다. Grok의 cohort-independent 설명은 기각. 의료 위험이 아니라 현재 데이터 안에서 큰/많은 표시를 탐색하는 정책. 과분할 잡음이 많은 성분을 만들 수 있다. 여러 사례가 같은1그룹에 남을 수 있다.

부모 결정: 그룹은 전체유효GT로 계산해 완료/핀/검색에 따라 바뀌지 않게 한다. 순서는 미완료→수동지정→그룹→ID, 완료는 뒤; 자료없음은 미평가이며 수동지정 가능. 같은그룹ID순은 임상우열이 아님. 헤더와 추천은 항상 전체 기본큐를 설명; 다른 정렬은 목록에만 적용.

검증예상(미완료/핀없음): 1그룹001,048 / 2그룹000,035 / 3그룹045. 실제값은 manifest 독립 계산으로 확인. 이는 치료·응급 우선순위의 정답이 아니다.
