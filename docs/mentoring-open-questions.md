# 다음 멘토링 확인 질문

> 목적: 구현으로 임의 확정하면 안 되는 사용자·평가·데이터 결정을 다음 회차에서 확인한다.

## 우선 질문

1. 실제 운영에서 이 대기열은 `즉시 반드시 확인`, `1~2주 안에 반드시 확인`, `가능하면 확인` 중 무엇을 뜻하는가? 먼저 확인 사례 때문에 일반 사례가 계속 밀리지 않게 할 규칙은 무엇인가?
2. 영상의학과 의료진과 의료영상 QA 담당자 중 누가 주 사용자이며, 두 역할의 권한과 업무 흐름은 어떻게 다른가?
3. 실제 업무에서 `먼저 확인`, `품질 확인`, `일반 순서` 세 라벨이 자연스러운가? 바꿔야 할 용어가 있는가?
4. 첫 데모에서 모델 불일치·작은 후보·영상 품질 중 반드시 남길 최소 신호는 무엇인가?
5. 실제 CT는 현재처럼 합성 우선순위 사례와 분리된 참고 영상으로 둘 것인가, 아니면 실제 모델 출력이 준비될 때까지 제품 화면에서 완전히 제외할 것인가?
6. 같은 검토량의 무작위 순서와 비교할 때 발표의 주 operating point를 상위 10%, 20%, 30% 중 어디로 둘 것인가? 주 KPI는 FN 부담 포착률과 민감도 중 무엇인가?
7. 순위결정전의 공식 심사 기준·제출 형식·데모 시간과 추가 기획 멘토링 가능 여부가 확정됐는가?
8. AI0에서 가져온 LiTS CT 3건의 정확한 원 출처·버전·사용조건과 외부 데모 허용 범위는 무엇이며, 비식별 자료라는 근거를 어떤 문서로 남길 것인가?
9. 순위 규칙이 장기간 일반 사례를 밀어내거나 특정 병변 크기·위치·하위집단을 늦추지 않는지 어떤 coverage·starvation·공통 실패·subgroup fairness 기준으로 확인할 것인가?

## 결정 전까지 유지할 경계

- 합성 대기열의 ID·순서·근거를 실제 LiTS CT와 연결하지 않는다.
- 실제 LiTS 영상의 분홍 표시는 데이터셋 GT이며 AI 예측이 아니다.
- 낮은 순위와 필터 밖 사례를 정상·안전·검토 불필요로 표현하지 않는다.
- 임상 위급도, 진단, 치료, 생존 개선을 주장하지 않는다.
