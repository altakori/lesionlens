# 2차 멘토링·영상의학과 MD 피드백 반영

상태: 로컬 시연 MVP 반영·검증 완료. 실제 환자–담당자 연결·병원 전송 및 임상 유효성 검증은 미구현/미검증으로 남긴다. 최신 사용자 요구가 이전 GT 크기·개수 기본 정렬과 병리학과 수신자 기획을 대체한다. 연구 평가 계약·원본 데이터는 변경하지 않았다.

## 목적과 범위
영상의학과 MD가 모델 간 검출 불일치와 작은 추가 병변 후보를 재검토하고, 필요하면 해당 환자의 임상과 주치의·담당 의료진에게 전달한다. AI는 누락 병변·악성·전이·응급도·치료·수술 가능 여부를 확정하지 않는다. 수신 MVP는 별도 웹 화면에서 수신·열람·수신 확인까지이며 판정·회신은 제외한다.

실제 병원 연락 시스템·환자 담당자 연결이 없는 로컬 앱이다. 시연 전송과 실제 전송을 명시적으로 분리한다. 실제 담당자 연결이 없으면 실제 전송은 차단한다. 시연은 명시적 시연 사례/담당자 연결에서만 수행하고 실제 연락·응급 수단이라고 안내하지 않는다. 원본·파생 CT·환자정보는 외부 worker나 Notion에 전달하지 않는다.

## 화면·동작 수용 기준
1. 최초 화면은 재검토 CT 목록. CT ID와 재검토 이유를 굵게, 후보 개수와 mL는 보조로 표시한다. 상단을 통계·모델 설정이 차지하지 않는다. 주요 태그는 ‘모델 간 불일치’, ‘작은 추가 후보’. 확인되지 않은 악성·전이·응급도 태그를 쓰지 않는다. 전체 CT 접근 유지, 일치≠정확/검토 불필요.
2. 개수는 3D 병변 후보(연결 성분) 수다. 확진 병변 수와 구분한다. 최대 후보 부피·전체 후보 부피·측정 모델을 따로 표시한다. 단순 개수 차이를 서로 다른 병변의 증거로 쓰지 않는다.
3. 후보 대응·검출 불일치 기반 재검토 순서를 설계한다. 작은 추가 후보의 정의, 모델 간 매칭, 정렬 및 동률 처리는 검증 전 잠정 기준으로 명시한다. GT 크기·개수/라디오믹스 그룹을 모델 기반 추천으로 바꾸어 부르지 않는다. 실제 후보 위치/모델 증거가 없으면 미산출로 표시한다.
4. 같은 카드에서 ‘AI 소견·Radiomics’를 펼친다. 실제 비교로 확인된 이유와 해당 모델·위치를 먼저, 정량 표와 별도 AI 소견을 아래에 둔다. 생성형 AI 소견이 없으면 없다고 표시한다. CT 확대 시 상세는 접고 핵심 이유 한 줄은 남긴다.
5. CT 보기는 모달 없이 같은 화면에서 확대. GT / CAPPY2 current / CAPPY2 050 / Baseline 네 패널을 동시에 표시한다. 기존 source key gt/cappyv2/cp050/baseline을 보존하고 사용자 표기는 위 이름으로 한다. GT는 참조 정답, 나머지는 예측. 결측을 다른 출처로 대체하지 않는다.
6. 네 패널은 같은 슬라이스·확대 위치·대비 조건. seg 마스크/테두리/박스 선택과 눈 아이콘 하나로 동시 표시 on/off. 다시 켜면 직전 방식 복원. 비동기 stale 요청·모델 결측·이미지 오류에서 이전 사례 표시가 섞이지 않는다.
7. ‘확인함’은 기본 미검토 목록에서 숨기되 삭제/정상 판정이 아니다. 미검토/검토 완료/전송됨/전체 필터, 다시 검토 기능. 기존 별도 데이터셋과 로컬 검토 기록을 보존한다.
8. ‘주치의에게 전송하기’는 문구 유지. 모달에 CT ID, AI 분석 요약·재검토 후보, MD 추가 소견·임상 메모, 참고 모델 다중 체크박스 또는 ‘모델 참고 없음’, 해당 사례 수신 담당자. 모델 참고 없음과 모델 선택은 상호배타적. 결측 모델 선택 금지. 해당 환자의 임상과 주치의/담당 의료진만, 병리학과 제외. 연결이 없으면 임의 수신자에게 보내지 않는다.
9. 보내기는 종이비행기 아이콘, 우상단 X 닫기. tooltip·접근성 이름·키보드·포커스 복원. 성공한 저장/전송 이후에만 확인함 자동 체크 및 전송됨 기록. 실패하면 메모/모델 선택 유지·재시도. 중복 전송 방지. 취소는 전송/검토 상태 불변. 메모 작성 후 닫기/Escape/배경닫기에는 폐기 확인.
10. 수신 화면은 전달 CT·AI 요약·후보·MD 메모·선택 모델 seg, 보낸 담당자·시각·수신 확인을 제공한다. 환자 연결과 모델 snapshot을 유지한다. 수신 확인과 진료 판단은 다르다. 시연 데이터는 시연임을 명시한다.
11. 병원 모델 입력 입구는 우상단 보조 영역, CT 비교 옆 배치 금지. 현재 UI-only 범위 유지(학습·업로드·추론 연결 안 함). 일반 검토는 확대/접기/펼치기, 전송만 확인 모달. 중요도가 다른 기능을 같은 수준으로 강조하지 않는다.
12. 1440/768/390/320px에서 overflow·가독성·접근성·주 행동 가시성 확인. 기능 테스트·실제 로컬 CT 정합성 검사·시각 QA를 분리 기록한다. 예전 테스트의 assertion을 약화하여 새 요구를 통과시키지 않는다.
