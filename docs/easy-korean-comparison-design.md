# 일반인 설명·모델 비교 UI 기준과 출처

## 사용자 요청과 범위
일반인 평가자도 의료진의 CT 재확인 흐름을 이해할 수 있도록 쉬운 한국어·아이콘+텍스트·사례별 이유를 우선한다. 실제 사용자는 영상의학과·병리학과 MD이며 일반인에게 임상 판정 역할을 맡기는 것은 아니다. 실제 CT를 임의로 위급/완치 가능/전이 위험으로 분류하지 않는다.

## 확인한 공식 웹 자료
1. 토스: 8가지 라이팅 원칙 https://toss.tech/article/8-writing-principles-of-toss
   - 다음 행동 예측, 중복 문구 제거, 핵심 메시지, 구어체, 불필요한 공포 유도 금지.
   - 적용: CT 보기 버튼의 결과가 분명하고 GT/절편 등의 표현은 쉽게 풀며 전문 정의는 자세히 보기에 둔다.
2. 토스: 좋은 에러 메시지를 만드는 6가지 원칙 https://toss.tech/article/how-to-write-error-message
   - 상황과 가능한 해결책, 적절한 정보량, 필요 이상으로 심각한 경고색을 피한다.
   - 적용: 실패 시 이전 이미지를 없애고 목록으로 돌아가 다시 열기 안내. 작은 표시나 AI 차이에 위급 빨간색을 부여하지 않는다.
3. 토스: 디자인 시스템 컴포넌트 설계 https://toss.tech/article/toss-design-system
   - 일관된 경험, 긴 텍스트와 다양한 화면, 읽기 기능, 열고 닫을 때 포커스.
   - 적용: 반응형 카드, 동일한 동작 버튼, 명시적 포커스 복귀, 44px 중심 터치 영역, reduced-motion.
4. 카카오톡 공식 서비스 소개 https://www.kakaocorp.com/page/service/service/KakaoTalk
   - 공식 화면의 폴더 분류, 짧은 말풍선, 익숙한 목록 탐색을 참고한다. 카카오의 내부 UX 원칙을 검증했다는 주장은 하지 않는다.
   - 적용: 이유별 분류, 짧은 설명 말풍선, 📋 전체 / 💬 AI 차이 / 🔎 작은 표시 / 📍 여러 표시 / 📌 먼저 볼 사례. 아이콘만으로 의미를 전달하지 않는다.
5. 카카오 Phocus 소개 https://tech.kakao.com/posts/615
   - 비개발자에게 기능을 이해시키려는 설명 방식과 이미지뷰어 맥락 참고. 접근성 구체 규칙의 출처로 확대 해석하지 않는다.

카카오 디자인·접근성 별도 사이트 및 W3C 일부 페이지는 조회 실패했다. 조회 실패 자료의 내용을 읽은 것으로 간주하지 않았다. 화면을 복제하거나 브랜드 자산을 가져오지 않았다.

## 데이터 근거
- ai0와 zebra를 명시된 SSH alias로 읽기 전용 조회. 새 추론·학습·GPU 할당·원격 수정 없음.
- zebra 기본 nnU-Net 및 CAPPYv2의 기존 후처리 예측, ai0 CP050 epoch1000 canonical 후처리 예측을 사용한다.
- case_000, case_001, case_035, case_048에 모델 3종씩; case_045는 기존 GT 사례로 유지하되 모델 결과 부재를 명시한다.
- case_035와 case_048 CT/GT 및 모델 예측 합계16개 파일을 원격 SHA256과 대조했다. 원격 상세 경로/receipt는 Git-ignored data/model_compare에만 보관한다.
- 기존 CT000/001과 실제 추론 입력의 SHA가 일치한다. GT는 압축 컨테이너가 달라도 affine과 전체 라벨 배열 동일성을 확인했다.
- 네 사례의 CT/예측 shape·effective affine이 일치한다. GT와 AI 예측을 동일한 영상 방향으로 변환한다.
- 사례 선택은 설명을 위한 기존 연구 자료 표본이며 공정 성능 비교나 독립 평가 코호트가 아니다. 기존 test27은 개발에 영향을 받은 연구 자료이므로 모델 우월성·일반화·전향적 성능 주장 금지.

## 측정·표현 경계
26-연결요소는 '표시 덩어리'이지 임상 병변 개수가 아니다. 모델 표시의 일치·차이는 신뢰도·위급도·전이 가능성·완치율이 아니다. 작은/여러 표시의 분류 기준은 계산상 탐색 기준임을 드러낸다. 정답 기반 측정과 모델 예측 기반 측정을 분리한다. 자료가 없으면 표시하지 않거나 없다고 알린다.
