# MD 검토 우선순위 워크플로 — 사용자 확정 요구사항

이 문서는 사용자가 확정한 제품 방향이며 기능 구현 완료나 임상 검증을 의미하지 않는다. 기존 기획의 사용자·화면 흐름과 충돌할 때 이 요구사항을 우선한다. 연구 평가 계약은 변경하지 않는다.

## 사용자와 목적
- 1차 사용자: 영상의학과 MD 및 병리학과 MD. 전문과별 세부 역할은 현장 확인 대상으로 둔다. 병리학과의 CT 단독 진단을 전제하지 않는다.
- 핵심 목적: 꼭 먼저 확인해야 할 CT를 검토 우선순위와 그 근거에 따라 살펴보도록 지원한다. 단순 영상 파일 탐색기나 병변 부피 내림차순 뷰어가 최종 제품 목표가 아니다.
- 순위는 검토 작업 순서이며 완치 가능성·전이 확률·임상 응급도와 동일하지 않다. 낮은 순위도 검토 대상에서 자동 제외하지 않는다.

## 승인된 화면 흐름
1. 대기열에서 영상 근거 카테고리와 사례 요약을 먼저 확인한다.
2. 사례별 카드에서 원본 사례명, 실제 측정값, 확인 항목, 우선순위의 근거를 확인한다.
3. 해당 카드의 `CT 보기` 버튼을 누른 경우에만 매칭된 CT 뷰어를 연다. 초기 진입이나 필터 변경만으로 CT를 자동으로 열지 않는다.
4. 뷰어에는 같은 사례의 CT·GT·절편 정보가 표시된다. 닫으면 목록의 검색·필터·정렬·스크롤 상태로 돌아간다.
5. MD가 검토 상태를 기록한다. 단순 CT 열람은 검토 완료나 병변 발견 성공을 뜻하지 않는다.

## 분류와 표시
- 영상 근거 카테고리: 병변 크기 확인 / 병변 개수 확인 / 병변 분포 확인. 다중 태그를 허용한다. 크기·개수·분포에 대한 측정 정의와 기준을 함께 공개한다.
- 실제 측정값이 없는 항목은 미측정으로 표시한다. GT 연결요소 개수를 임상적으로 확정된 종양 개수로 단정하지 않는다.
- 현재 공개 LiTS 사례의 GT 기반 측정은 정답 주석에서 계산한 관찰값으로 표시한다. 모델 예측·전향적 자동 위험 평가와 구분한다.
- 완치율·전이 가능성·응급도 항목을 표시할 경우 모두 `평가 전`으로 둔다. 근거 없이 수치·등급을 만들지 않는다.
- 작은 병변 → 높은 완치율, 다발성 병변 → 전이, 큰 부피 → 응급이라는 대응은 금지한다.
- 상단의 반복 데모 문구는 넣지 않는다. GT 표기와 접근 가능한 출처·사용 범위 안내는 유지한다.

## 우선순위 구현 전 확정 사항
- 사용자는 우선순위 워크플로를 승인했지만 크기·개수·분포의 임계값·가중치·우선순위 방향·동점 처리까지 정하지 않았다.
- 임의 가중치나 부피순을 검증된 의료 우선순위로 포장하지 않는다. 제안 규칙은 초안으로 구분하고 MD 검토 및 연구 평가 계약에 따라 확정한다.
- GT 기반 사례 탐색과 실제 모델 신호 기반 우선순위는 별도 층으로 관리한다. 모델 결과가 없으면 모델 불일치나 탐지 신뢰도를 꾸며내지 않는다.

## 구현 확인 항목
- [ ] 최초 화면은 카테고리와 사례 카드이며 CT는 닫혀 있다.
- [ ] 원본 사례 ID와 카드·측정값·CT·GT가 일치한다.
- [ ] 순위 이유 및 측정 출처가 보이고 전체 검사를 유지한다.
- [ ] `CT 보기` 이후에만 해당 CT를 열고, 닫기·Escape·포커스 복귀를 지원한다.
- [ ] 카테고리·검색·정렬 후에도 사례 매칭과 목록 상태가 유지된다.
- [ ] 평가 전 항목을 수치·위험색·등급으로 암시하지 않는다.
- [ ] 병변 측정 정의, 순위 규칙 및 근거 수준을 문서화하고 테스트한다.
