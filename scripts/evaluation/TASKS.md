# 수동 사용성 과제 안내

실제 참여 기록이 아직 없다면 usability_template.csv를 그대로 둡니다. 예시 사람이나 가상 MD 기록을 채우지 마세요. 테스트는 임시 합성 기록만 사용합니다. 수집 전 참여자에게 목적·기록 항목을 설명하고 소속 기관의 필요한 절차를 따르세요.

## 세 과제

1. **사례 선택과 표시 설명**: 사례 하나를 선택하고 GT(참조 주석)와 모델 예측 표시를 구별해 설명합니다. 순위는 정해진 특징의 검토 순서이며 진단·위험도·안전성 보장이 아님을 본인의 말로 설명합니다. 관찰자가 수동으로 과제 완료 및 GT 혼동 여부를 기록합니다.
2. **같은 슬라이스 비교**: GT와 모델을 같은 사례·같은 슬라이스 위치에서 비교합니다. 위치를 맞춘 뒤 관찰한 표시 차이를 설명합니다. 관찰자는 위치를 맞추었는지 확인하여 완료 여부를 기록합니다. 정확한 진단 여부를 채점하지 않습니다.
3. **모델 누락 확인 및 검토 기록**: 모델 출력이 없는 사례를 확인하고 누락 사실과 검토 기록을 남깁니다. 누락을 안전 또는 이상 없음으로 해석했는지 관찰자가 기록합니다. 모델 미제공과 주석 없음, 진단 음성을 구분합니다.

## 기록 규칙

각 가명-과제 조합은 한 행입니다. participant_pseudonym에는 P001 같은 가명만 씁니다. role은 team(팀원), lay(비의료 일반 참여자), MD(의사) 중 실제 역할 하나로 고정합니다. task_id는 1/2/3입니다. elapsed_seconds는 시작부터 종료까지의 유한한 비음수 초입니다. completed, GT_confusion, missing_means_safe는 true 또는 false로 수동 입력합니다. completed는 해당 과제 수행 완료 관찰이며 자동 이해도 점수가 아닙니다. GT_confusion은 참조 주석과 예측을 혼동한 관찰, missing_means_safe는 누락을 안전하다고 해석한 관찰입니다.

부분 작성 행이나 미관찰 항목을 false/0으로 채우지 마세요. 필수 관찰이 완료된 행만 입력하세요. 미실시 과제는 행을 만들지 않으며 요약에 누락 과제로 표시됩니다. 모든 필드가 빈 행은 빈 템플릿 행으로 무시하지만 개수는 보고합니다. notes는 선택적이며 개인정보 없는 짧은 관찰 메모만 입력합니다. 이름·연락처·환자정보·실제 사례 식별자를 넣지 마세요. 도구는 자유 텍스트 개인정보를 탐지하지 않으며 보고서에 notes를 복제하지 않습니다.

```bash
python3 usability_records.py --input usability_template.csv --output outputs/usability --source-kind supplied_evaluation
```

출력 폴더에 report.json과 report.md를 만듭니다. 빈 템플릿 결과는 not_collected, participant_count=0, metrics=null입니다. 역할별·과제별 비율의 분모는 실제로 입력한 기록 행 수입니다. 참여자 수와 다릅니다. 기록이 없는 MD 역할은 0명/null이며 임상 평가를 의미하지 않습니다. 실제 수집과 진위는 운영자가 확인해야 합니다.
