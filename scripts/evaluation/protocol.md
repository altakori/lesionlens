# P1 후향적 구조 진단 프로토콜

이 도구는 후향적 순위 구조 진단용이다. 사전 등록된 임상 근거가 아니며, 진단·안전성·임상 효용을 판단하지 않는다. 코드 테스트는 합성 자료만 사용한다. 이와 별도로 부모 작업공간에서 실제 로컬 구조 CSV를 이용한 후향적 기술 진단을 수행할 수 있다. 이 bounded worker는 실제 CSV를 열지 않으며 실제 참여자 평가를 수행하지 않는다.

사용자가 보고한 부모의 real24 구조 비교(주석 있는 양수 측정 행 20개 / 주석 없음 4개)는 **기술적 구조 비교만** 의미한다. 양수 측정은 양성 진단이 아니며 주석 없음도 음성 진단이 아니다. 이 문서는 해당 결과를 독립 검증하거나 임상 근거로 승격하지 않는다.

## 실행 출처와 재현성

모든 CLI는 --source-kind를 명시해야 한다. synthetic은 합성 테스트/시연 입력, local_structural은 실제 로컬 CSV의 후향적 구조 진단, supplied_evaluation은 외부에서 제공한 평가 라벨/수동 관찰 기록을 뜻한다. API도 source_kind를 명시해야 한다. 이는 운영자 선언이며 도구가 자료의 출처를 인증하지 않는다. source_kind_verified 및 independent_split_verified는 항상 false이다.

각 JSON provenance에 입력 SHA-256, 실행 코드 4개 파일의 SHA-256, 이 protocol.md의 SHA-256, 실행 argv 배열, cwd, Python 버전을 기록한다. CLI argv는 실제 명령 인수를 보존한다. API는 같은 평가를 재현할 CLI 인수와 replay_reports/<도구명> 출력 경로를 제공한다. 재현은 기록된 코드/프로토콜/입력과 Python 환경이 보존된 경우에 한한다. 출처 유형과 무관하게 결과는 exploratory이며 독립 분할이나 임상 효용을 주장하지 않는다.

## 가설과 승격 제한

- H0 (구조적 작업 가설): 축을 추가하면 같은 Pareto 그룹에 속하는 사례(순위 동률)가 늘어난다. 이는 통계적 영가설 검정이나 확정된 사실이 아니다. 그룹 크기와 최대 그룹 비율을 기술적으로 비교한다.
- 순위 동률과 완전히 동일한 특징 벡터를 구분한다. 더 많은 축은 지배 관계를 줄일 수 있으며 효용 증가를 뜻하지 않는다.
- 독립적으로 계산된 효용 라벨과 독립 평가 없이는 후보 순위를 승격하지 않는다. 이 도구는 분할 독립성, 라벨 생성 과정, 프로젝트 지표 계약 준수를 검증하지 않는다.

## 고정 순위 계약

가중치·튜닝 없이 큰 값을 우선하는 Pareto 층을 1부터 매긴다. 한 사례가 모든 축에서 같거나 크고 적어도 한 축에서 크면 다른 사례를 지배한다. 각 층을 제거한 후 다음 층을 구한다.

- 4축: largest_component_ml, component_count, glcm_joint_entropy_bin25, **음수** absolute_tumor_liver_contrast_hu.
- 명세에 2축 정의가 별도로 지정되지 않아 형태 기준선은 4축의 구조적 부분집합인 **largest_component_ml, component_count**로 고정한다. maximum_3d_diameter_mm 및 sphericity는 검증·기술용 측정값이며 순위에 사용하지 않는다. 이 선택은 의학적 의미를 부여하지 않는다.
- CSV review_group은 4축 재계산 결과와 반드시 일치해야 한다. 그룹 내 표시 순서는 case_id 문자열 오름차순이다. display_order는 순위를 바꾸지 않는다.
- 큰 부피 순서(동률 시 ID) 및 ID 순서는 같은 완전한 특징 보유 코호트에만 제공한다.
- bin50 특징은 입력에 없으므로 review_group_bin50은 출처 그룹과의 일치율 및 전이만 기술한다. 재계산된 특징 안정성이라고 부르지 않는다. 누락된 bin50 그룹은 별도 보고한다.

## 결측 및 주석 없음

열은 모두 필요하지만 결측 값은 빈 문자열로 표시한다. case_id는 고유하고 비어 있으면 안 된다. 숫자 측정값이 있으면 유한·비음수여야 하며 component_count는 정수여야 한다. 그룹은 1 이상의 정수이다. 임의 NA/NaN/inf 표기는 허용하지 않는다. 모든 숫자 입력 및 FN 총합은 유한한 Python float로 표현 가능한 크기로 제한한다. 순위의 소수 비교는 Decimal로 수행한다.

sphericity는 값이 있으면 **0 ≤ sphericity ≤ 1**이어야 한다. 경계 0과 1을 허용한다. 이산 측정 오차에 대한 근거 있는 허용오차 계약이 제공되지 않았으므로 허용오차는 0이다. 경계 밖 값은 오류로 보고하며 반올림·클리핑·실제 측정값 변경을 하지 않는다. 측정 방법상 다른 범위가 필요하면 원본 측정 계약을 검토한 뒤 프로토콜을 명시적으로 수정해야 한다.

- review_group이 빈 값이고 부피와 개수가 모두 0이면 `no_tumor_annotation`이다. 음성 진단이 아니다. 이때 bin50 그룹도 비어 있어야 하고 나머지 측정값은 0 또는 결측이어야 한다.
- 부피 또는 개수가 0이면 둘 다 명시적으로 0이어야 한다. 0과 양성 값 또는 결측의 혼합은 오류이다.
- 부피와 개수가 모두 양수이고 모든 측정값이 있으면 순위 코호트이다. 이 경우 지름도 양수이고 원본 review_group도 필수이다. 엔트로피·절대 대비·구형도 0은 허용한다.
- 다른 결측은 `unknown`으로 명시적으로 보고하고 제외한다. 불완전한 행에 원본 그룹이 있으면 오류이다. 완전한 특징인데 그룹이 비어 있으면 오류이다. 제외 목록·이유·개수·해시를 출력한다. unknown은 조용히 버리지 않는다.
- clinical_urgency, sample_stratum, interpretation은 읽되 판단·점수화하지 않는다. 빈 값도 허용한다. 자유 텍스트를 출력 보고서에 복제하지 않는다.

## 동일 코호트 FN 부담 평가

별도 CSV에는 case_id, candidate_rank, **실제 largest_component_ml 및 disagreement_score 측정값**, 독립 계산 fn_count가 필수이다. 측정값은 유한 비음수이며 결측을 허용하지 않는다. volume_rank와 disagreement_rank는 각 측정값 내림차순, 동률 시 case_id 문자열 오름차순으로 직접 계산한다. 두 원본 순위 열은 선택적으로 남길 수 있지만 있으면 모든 행의 값이 계산 결과와 일치해야 한다. 역순 등 임의의 순열을 이름만 붙여 기준선으로 사용할 수 없다. 불일치 점수의 생성 방법·단위·프로젝트 계약은 공급자가 기록해야 하며 도구는 그 측정 진위를 검증하지 않는다.

candidate_rank는 같은 N행에 대한 정확한 1..N 순열이어야 한다. 후보 동률 해소 규칙은 공급자가 사전에 고정한다. 결측 라벨을 0으로 채우거나 부피·불일치 점수 등 순위 특징에서 FN 라벨을 생성하지 않는다. k개 검토 시 선택한 사례의 FN 개수를 합산하고 전체 FN 개수로 나눈다. 이는 **사례별 FN 부담 포착률이며 임상 민감도가 아니다**. 총 FN=0이면 비율은 null이다. 무작위 기대 부담은 정확히 k/N × 총 FN이다. 선택적 시뮬레이션은 명시한 seed/repeats로 수행하며 2.5–97.5 백분위 범위를 Monte Carlo 구간으로 표시한다. 신뢰구간이 아니다. 모든 결과는 exploratory이다.

## 수동 사용성 기록

세 과제의 수동 관찰만 요약한다. 역할 team/lay/MD를 분리한다. 빈 템플릿은 미수집 상태이며 지표는 null이다. 가명만 쓰며 이름·연락처·환자정보를 기록하지 않는다. 자동 의학 이해 점수 및 임상의 근거를 생성하지 않는다. 실제 기록의 진위와 자유 텍스트의 개인정보 부재는 도구가 검증할 수 없다.
