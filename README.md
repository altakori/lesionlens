# LesionLens

작은 간 종양을 놓칠 위험이 높은 CT를 먼저 재검토하도록 돕는 교육·연구용 대시보드 MVP입니다.

## 현재 범위

- 합성 사례 기반 재검토 대기열
- 모델 불일치·작은 병변 후보·영상 품질 근거 표시
- 상위 10/20/30% 업무량 비교
- 우선/일반/품질 확인 상태 표시
- 사례를 클릭하면 열리는 24절편 합성 CT 뷰어
- 슬라이더·마우스 휠·방향키 절편 탐색과 병변 후보 오버레이
- 실제 진단·치료 결정을 하지 않는 human-in-the-loop 데모

## 실행

의존성 없이 실행됩니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 테스트

```bash
npm test
```

## 안전 경계

- 저장소에는 공개 가능한 코드와 합성 데이터만 포함합니다.
- DICOM, 환자 식별자, 실제 임상 메타데이터, 모델 체크포인트를 커밋하지 않습니다.
- 점수는 종양 확률이 아니라 “추가 확인 가치”를 뜻합니다.
- 임상 성능과 일반화를 입증하는 제품이 아닙니다.

## 다음 단계

1. 멘토와 1차 사용자·주 KPI·최소 데모 화면을 확정합니다.
2. 공개 데이터의 이용조건과 코호트 버전을 확인합니다.
3. 환자 단위 train/calibration/held-out 분리와 평가 계약을 코드로 동결합니다.
4. 고정 평가셋에서 같은 업무량의 무작위 대기열과 비교합니다.
