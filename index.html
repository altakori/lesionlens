재검토 대기열

모든 사례는 대기열에 유지됩니다. 아래 카테고리는 관찰된 합성 영상 특징을 탐색하는 필터이며 임상 위험도·안전·정상 여부를 판정하지 않습니다.

의료 표현 경계: 작은 후보는 완치 가능성을, 다발성·분포는 전이 위험을 예측하지 않습니다. 의료진 검토 전에는 임상 위험도 카테고리로 사용하지 않습니다.

사례를 선택하면 오른쪽에서 선정 이유·확인 항목·한계를 볼 수 있습니다.

서로 다른 모델이 다르게 표시한 사례를 의료진에게 설명해, 다시 볼 순서를 정하는 보조 흐름을 검토합니다.

현재 사용자 가정

영상의학과 의료진 · QA 담당자

의료진의 재검토와 QA 담당자의 실패 신호 확인을 가정한 설계입니다. 역할 우선순위와 실제 사용 흐름은 의료진 검토가 필요합니다.

어디까지 하나

순서와 근거만 제안

진단·치료·임상 위급도를 판단하지 않습니다. 환자 편익은 후속 검증 가설이며 현재 MVP의 입증 결과가 아닙니다.

One review flow

한 대기열에서 하는 일

  1. 1. 모든 사례를 유지낮은 신호도 버리거나 정상으로 판정하지 않습니다.
  2. 2. 먼저 볼 이유를 확인사례 카드와 상세 화면에서 여러 근거와 한계를 함께 봅니다.
  3. 3. 원래 판독·QA 흐름에서 재확인현재 합성 사례에는 원본 영상이 연결되지 않으므로 실제 적용 단계의 행동을 명확히 구분합니다.

Case map before categories

현장 사례를 먼저 나열하고 작업 순서로 묶었습니다.

작업 순서 라벨과 영상 특징 카테고리를 구분합니다. 대표 라벨은 다음 행동을 안내하고, 한 사례에 큰 후보·작은 후보·다발성 분포·경계 인접·모델 불일치·영상 품질이 겹치면 상세에 모두 남깁니다. 사용자 검토 전 임상 위험도 기준으로 확정하지 않습니다.

먼저 확인

모델 위치·부피 불일치

마스크 차이와 연결요소 수 차이를 함께 표시합니다. 두 모델의 공통 실패는 찾기 어렵습니다.

먼저 확인

한 모델만 표시한 작은 후보

작은 연결요소와 모델 단독 후보를 근거로 남깁니다. 후보는 병변 확률이 아니며 오탐일 수 있습니다.

먼저 확인

간 경계 인접 후보

경계부 마스크 변동을 확인 대상으로 표시합니다. 위치만으로 임상 위험을 판단하지 않습니다.

품질 확인

절편 간격·영상 품질 이상

모델 결과를 해석하기 전에 기술적 품질을 확인합니다. 품질 신호는 질환 위험과 별개입니다.

일반 순서

모델이 대체로 일치

현재 별도 트리거가 없어도 모든 사례를 유지합니다. 정상 판정이 아니며 공통 실패 가능성이 남습니다.

현재 범위 밖

응급도·전이·완치 가능성

현재 입력과 검증으로 계산하지 않습니다. 임상 정보, 의료진 기준, 별도 승인과 검증 없이는 화면에 제시하지 않습니다.

Evidence boundary

보여주는 것과 아직 확인할 것을 분리합니다.

현재 데모

합성 대기열 흐름

정렬·필터·사례 근거·한계 표시와 로컬 CT 조작을 검증합니다. 실제 임상 성능을 주장하지 않습니다.

근거 연결 필요

데이터·모델 신뢰 정보

데이터셋 출처·버전·라벨 범위·사용조건·비식별 근거와 모델 provenance, held-out 성능을 확인해야 합니다.

후속 범위

기관별 재학습·통합

기관별 재학습, 임계값 조정, 원내 PACS 연동은 데이터·기술·승인 조건이 준비된 뒤 별도로 검토합니다.

외부 확인

의료진·주최 측 질문

의료진에게 사례 분류와 최소 신호를, 주최 측에 심사 기준·제출 형식·추가 멘토링 가능 여부를 확인합니다.
